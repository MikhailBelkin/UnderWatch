# За стеклом (UnderWatch)

Маленькая нарисованная квартира, в которой живёт персонаж с собственным разумом. Он сам решает, чем заняться: готовит, читает, звонит маме, принимает душ, слушает пластинки. У него есть потребности, эмоции по Экману, характер и долгая память. С ним можно разговаривать, влиять на его мир (свет, техника, потоп), проявлять нежность и дарить подарки.

Решения принимает Claude через Claude Code (`claude -p`), поэтому отдельный API-ключ не нужен: используется вход в аккаунт claude.ai.

## Как это устроено

- `server/app.py` — запуск сервера и команда `passwd`. Сервер работает круглосуточно, но каждый жилец бодрствует только в свои часы. Ночью модель не вызывается. Только стандартная библиотека Python.
- `server/underwatch/` — весь код сервера:
  - нижний этаж: `config` (окружение), `storage` (базы), `passwords`, `context` (чей это жилец: текущий персонаж запроса), `clock` (время и распорядок), `settings` (настройки жильца), `world` (квартира: места, комнаты, список действий), `brain` (модели: Ollama или Claude, пауза);
  - `life/` — жизнь персонажа: `state` (состояние), `emotions`, `needs`, `bonds` (отношения с гостем), `goals`, `gifts`, `drawings` (рисунки вещей и существ), `prompts` (что видит модель), `memory` (память разговора), `mind` (решения, утро, вечер, чат, цикл жизни), `guest` (вмешательства гостя);
  - `life/body/` — что делает тело: `plan` разбирает цепочку действий от модели, `act` её выполняет, а каждое действие — своя функция в модуле по теме: `devices` (телевизор, приставка, музыка, свет), `clothes` (переодевание), `hygiene` (душ, туалет), `kitchen` (готовка, еда, посуда), `rest` (сидеть, лечь, спать), `house` (протечка), `moves` (свободные движения), `company` (время вместе, выгнать существо);
  - верхний этаж: `residents` (жильцы: загрузка, создание, «начать заново»), `accounts` (пользователи: пароли, сессии, приглашения, регистрация), `web` (HTTP: страницы, API, HTTPS).
- `web/index.html` — квартира в разрезе (canvas) и интерфейс. Страница сама ничего не решает: она показывает и анимирует то, что решил сервер (SSE). `web/register.html` — регистрация.
- `deploy/za-steklom.service` — шаблон службы systemd.

### Что есть у персонажа

- **Квартира:** спальня, гостиная, кухня с барным стулом, санузел; свет по комнатам, телевизор, приставка, проигрыватель, плита, холодильник, душ. Сидеть, лежать и вставать можно на любую подходящую поверхность: кровать, диван, ковёр, журнальный столик, стул, столешницу.
- **Тело:** готовые действия (готовка по шагам, переодевание у шкафа, душ за матовым стеклом, туалет за ширмой, мытьё посуды) и свободные движения: модель сама описывает ключевые позы (углы суставов, наклон тела), а тело опирается на пол нужной точкой — планка, отжимания, ласточка, ползти на четвереньках.
- **Потребности:** сытость, бодрость, развлечённость, общение, свежесть, туалет — со словесным состоянием и скоростью изменения.
- **Эмоции:** базовые по Экману и социальные чувства (смущение, ревность, скучание), мимика по FACS и поза. Если гостя долго нет — скучает, грустит, может ревновать и написать первой.
- **Характер** (9 шкал) и **личность**, которую задаёт игрок: основа «кто он/она» главнее всего, а заметки о себе персонаж обновляет каждый вечер.
- **Две цели.** Главная — узнать гостя и сблизиться: факты о госте по темам, знакомство в процентах, близость с уровнями, которая только растёт. Локальная — проект на несколько дней (например, задержка дыхания или шпагат): программа, тренировки, правдоподобный прогресс, этапы.
- **Гость может:** вмешиваться (свет, техника, потоп или своё событие), проявлять нежность (готовые жесты или своё), дарить подарки и выполнять её желания, приглашать на свидание, кино, танцы, ужин или своё занятие вдвоём.
- **Нарисованные подарки и гости:** подарок и своё вмешательство Sonnet рисует на лету как SVG: вещь появляется на своём месте (полка, подоконник, тумбочка, столик, кухня), персонаж берёт её в руки и сочетает с другими (телефон — на зарядку, кофе — в турке и в чашку). Птицы летают, пауки ползают по стене, мыши бегают; их можно убрать в меню «Вмешаться», а персонаж может выгнать сам. Большое, абстрактное и неузнаваемое не рисуется. Рисунки кэшируются.
- **Гардероб:** обычная одежда, пижама, платье, шорты, джинсы со свитером, мини, купальник, бельё, халат, полотенце.

## Запуск

Нужны Python 3.9+ и Claude Code, в котором выполнен вход (`claude` в PATH или расширение VS Code; путь можно задать через `CLAUDE_BIN`).

```bash
git clone https://github.com/MikhailBelkin/UnderWatch.git ~/UnderWatch
cd ~/UnderWatch
PASSWORD=change-me python3 server/app.py   # http(s)://127.0.0.1:8765, вход: mike / change-me
```

Как служба, которая переживает перезагрузку и выход из системы:

```bash
mkdir -p ~/.config/systemd/user ~/UnderWatch/data
cp deploy/za-steklom.service ~/.config/systemd/user/   # поправьте PASSWORD и пути
systemctl --user daemon-reload && systemctl --user enable --now za-steklom
loginctl enable-linger "$USER"                        # чтобы жила без входа в систему
tail -f ~/UnderWatch/data/server.log
```

Разум может работать и на локальной модели, бесплатно и без лимитов подписки: нужна [Ollama](https://ollama.com) (служба на `127.0.0.1:11434`) и модель `qwen3.5:27b` (`ollama pull qwen3.5:27b`, загруженная занимает около 18 ГБ видеопамяти). Переключатель — ☰ → «Настройки» → «Разум»: локальная модель или Claude, выбор быстрой и глубокой модели и галочка «если локальная модель не ответила — спросить Claude». Кнопка ☰ → «Остановить разум» выгружает модель и освобождает видеокарту; пока разум на паузе, жилец ничего не решает и отвечает заготовкой.

## Пользователи и HTTPS

У каждого пользователя свой логин, пароль и свой жилец в своей квартире (`data/residents/<id>.sqlite`). При первом запуске прежняя однопользовательская квартира становится жильцом владельца: логин `mike` (или `OWNER_LOGIN`), пароль — из `PASSWORD`. Пароли хранятся как PBKDF2 с солью, у каждого устройства своя сессия; после 5 неверных попыток вход закрывается на 15 минут.

Регистрация — только по приглашению: владелец создаёт одноразовые коды в ☰ → «Пользователи и приглашения…» и отправляет их вместе со ссылкой `/register`. При регистрации человек задаёт логин, пароль, как к нему обращаться, и придумывает жильца: пол, имя, возраст, профессию, увлечения, кем жилец будет (романтический друг — только 18+, близкий друг, друг по интересам, наставник по целям), общительность, разговорчивость и характер. Жильцы других пользователей живут только на локальной модели; Claude, выбор модели и остановка разума — у владельца.

HTTPS включается сам, если есть `data/tls/cert.pem` и `data/tls/key.pem`. Самоподписанный сертификат (браузер один раз предупредит):

```bash
mkdir -p data/tls && openssl req -x509 -newkey rsa:2048 -nodes -days 825 -subj "/CN=UnderWatch" \
  -addext "subjectAltName=DNS:localhost,IP:127.0.0.1,IP:<адрес в сети>" -keyout data/tls/key.pem -out data/tls/cert.pem
```

## Настройки

Всё меняется в меню ☰ → «Настройки» и хранится в базе: жилец (он/она, имя), звук, личность и память, распорядок, скорость голода, характер.

☰ → «Начать заново…» сбрасывает игру: жилец забывает разговоры, дневник, заметки о себе и о госте, подарки, желания, близость и цели. Имя, пол, основа личности, характер, распорядок и статистика расхода остаются.

Переменные окружения:

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `HOST`, `PORT` | адрес сервера | `127.0.0.1`, `8765` |
| `PASSWORD` | первый пароль владельца (дальше меняется в настройках) | пусто — случайный, печатается в лог |
| `OWNER_LOGIN` | логин владельца при первом запуске | `mike` |
| `WAKE_HOUR`, `SLEEP_HOUR` | часы по умолчанию, пока их не поменяли в настройках | `8`, `16` |
| `RESIDENT_TZ` | часовой пояс | `Europe/Ljubljana` |
| `MODEL_FAST`, `MODEL_DEEP` | модели для решений и для плана с рефлексией | `haiku`, `sonnet` |

Состояние, события, дневник и расход лежат в `data/mind.sqlite` (в репозиторий не попадает).

## Расход

Вызовы идут через Claude Code и тратят лимиты аккаунта claude.ai. Сумма в долларах на странице — оценка по прайсу API, для справки. Типичное решение стоит 3–5 тысяч токенов на входе и 150–300 на выходе.
