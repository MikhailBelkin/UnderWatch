# За стеклом (UnderWatch)

Маленькая нарисованная квартира, в которой живёт персонаж с собственным разумом. Он сам решает, чем заняться: готовит, читает, звонит маме, принимает душ, слушает пластинки. У него есть потребности, эмоции по Экману, характер и долгая память. С ним можно разговаривать, влиять на его мир (свет, техника, потоп), проявлять нежность и дарить подарки.

Решения принимает Claude через Claude Code (`claude -p`), поэтому отдельный API-ключ не нужен: используется вход в аккаунт claude.ai.

## Как это устроено

- `server/app.py` — разум и мир. Работает круглосуточно, но персонаж бодрствует только в заданные часы (по умолчанию 8:00–17:00, Europe/Ljubljana). Ночью модель не вызывается. Только стандартная библиотека Python.
- `web/index.html` — квартира в разрезе (canvas) и интерфейс. Страница сама ничего не решает: она показывает и анимирует то, что решил сервер (SSE).
- `deploy/za-steklom.service` — шаблон службы systemd.
- `prototype/artifact.html` — первая версия-прототип для claude.ai Artifacts, без сервера.

| Когда | Что | Модель |
|---|---|---|
| утром | план на день | Sonnet |
| закончилось занятие, что-то случилось, сильно захотелось есть или в туалет | мысль, намерение, действия, эмоция | Haiku, без размышления |
| гость написал | ответ, действие, эмоция, иногда желание получить подарок | Haiku, без размышления |
| вечером | дневник за день и переписывание заметок о себе и о госте (сжатие памяти) | Sonnet |
| ночью | спит, на сообщения бормочет заготовками | — |

### Что есть у персонажа

- **Квартира:** спальня, гостиная, кухня с барным стулом, санузел; свет по комнатам, телевизор, приставка, проигрыватель, плита, холодильник, душ. Сидеть, лежать и вставать можно на любую подходящую поверхность: кровать, диван, ковёр, журнальный столик, стул, столешницу.
- **Тело:** готовые действия (готовка по шагам, переодевание у шкафа, душ за матовым стеклом, туалет за ширмой, мытьё посуды) и свободные движения: модель сама описывает ключевые позы (углы суставов, наклон тела), а тело опирается на пол нужной точкой — планка, отжимания, ласточка, ползти на четвереньках.
- **Потребности:** сытость, бодрость, развлечённость, общение, свежесть, туалет — со словесным состоянием и скоростью изменения.
- **Эмоции:** базовые по Экману и социальные чувства (смущение, ревность, скучание), мимика по FACS и поза. Если гостя долго нет — скучает, грустит, может ревновать и написать первой.
- **Характер** (9 шкал) и **личность**, которую задаёт игрок: основа «кто он/она» главнее всего, а заметки о себе персонаж обновляет каждый вечер.
- **Две цели.** Главная — узнать гостя и сблизиться: факты о госте по темам, знакомство в процентах, близость с уровнями, которая только растёт. Локальная — проект на несколько дней (например, задержка дыхания или шпагат): программа, тренировки, правдоподобный прогресс, этапы.
- **Гость может:** вмешиваться (свет, техника, потоп или своё событие), проявлять нежность (готовые жесты или своё), дарить подарки и выполнять её желания, приглашать на свидание, кино, танцы, ужин или своё занятие вдвоём.
- **Гардероб:** обычная одежда, пижама, платье, шорты, джинсы со свитером, мини, купальник, бельё, халат, полотенце.

## Запуск

Нужны Python 3.9+ и Claude Code, в котором выполнен вход (`claude` в PATH или расширение VS Code; путь можно задать через `CLAUDE_BIN`).

```bash
git clone https://github.com/MikhailBelkin/UnderWatch.git ~/UnderWatch
cd ~/UnderWatch
PASSWORD=change-me python3 server/app.py   # http://127.0.0.1:8765
```

Как служба, которая переживает перезагрузку и выход из системы:

```bash
mkdir -p ~/.config/systemd/user ~/UnderWatch/data
cp deploy/za-steklom.service ~/.config/systemd/user/   # поправьте PASSWORD и пути
systemctl --user daemon-reload && systemctl --user enable --now za-steklom
loginctl enable-linger "$USER"                        # чтобы жила без входа в систему
tail -f ~/UnderWatch/data/server.log
```

## Настройки

Всё меняется в меню ☰ → «Настройки» и хранится в базе: жилец (он/она, имя), звук, личность и память, распорядок, скорость голода, характер.

Переменные окружения:

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `HOST`, `PORT` | адрес сервера | `127.0.0.1`, `8765` |
| `PASSWORD` | пароль на страницу; пустой — без пароля | пусто |
| `WAKE_HOUR`, `SLEEP_HOUR` | часы по умолчанию, пока их не поменяли в настройках | `8`, `16` |
| `RESIDENT_TZ` | часовой пояс | `Europe/Ljubljana` |
| `MODEL_FAST`, `MODEL_DEEP` | модели для решений и для плана с рефлексией | `haiku`, `sonnet` |

Состояние, события, дневник и расход лежат в `data/mind.sqlite` (в репозиторий не попадает).

## Расход

Вызовы идут через Claude Code и тратят лимиты аккаунта claude.ai. Сумма в долларах на странице — оценка по прайсу API, для справки. Типичное решение стоит 3–5 тысяч токенов на входе и 150–300 на выходе.
